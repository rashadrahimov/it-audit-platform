# Шрифты для PDF-экспорта (T-045)

DejaVu Sans (Bitstream Vera License, свободное распространение и встраивание) —
единственный шрифт с полным покрытием кириллицы и азербайджанской латиницы
среди свободных. Встроен в репозиторий (не системный), т.к. on-prem-артефакт
не должен зависеть от шрифтов хоста (ADR-0002 single artifact).
