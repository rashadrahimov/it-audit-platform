# Первый релиз — полный объём требований; разработка соло с AI-инструментами

Первый релиз включает весь описанный клиентом объём (ядро аудита, AI-подбор чеклистов и findings, risk-based планирование, риск-реестр, universe), а не урезанный MVP — таково ожидание якорного клиента. Разработчик один, с опорой на AI-инструменты (Claude Code и др.). Компенсация рисков длинного цикла: жёсткая внутренняя фазировка с демо клиенту каждые 2–4 недели (ядро аудита строится первым — оно даёт ~60% ценности), архитектура — монолит с минимумом движущихся частей. Ориентир срока: 8–12 месяцев до полного объёма.
