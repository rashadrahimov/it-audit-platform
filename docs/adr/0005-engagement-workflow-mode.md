# Workflow engagement'а: полный цикл, режим выбирается при создании

Жизненный цикл engagement'а реализован как одна state machine с классическим циклом внутреннего аудита: черновик чеклиста → ревью менеджера → отправка респондентам → сбор ответов → черновики findings → ответ менеджмента аудируемого → утверждение approver'ом → выпуск отчёта → follow-up до закрытия findings. При создании engagement'а выбирается режим: «формальный» (все переходы принудительные) или «облегчённый» (этапы согласования можно пропускать — для экспресс-оценок). Рассмотренные альтернативы: единый цикл с override'ами (отвергнут — клиентские команды хотят явно разные типы заданий) и настраиваемый workflow-движок (отвергнут как преждевременный — 2-3 месяца разработки до первой продажи). Оба режима живут в одной state machine, чтобы отчёты, уведомления и дашборды не раздваивались.
