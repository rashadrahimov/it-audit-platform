# Лицензирование: по числу дочек + по местам аудит-команды

По решению клиента ([[client-answers]]) стоимость лицензии считается по двум произвольно настраиваемым величинам: **число дочерних компаний (Subsidiary)** в группе и **число мест аудит-команды (audit seats)**. Обе величины не фиксированы — тенант может иметь любое количество.

Следствие для модели данных: вводятся сущности **License/Plan** и **Quota** на уровне тенанта с лимитами по subsidiaries и по seats, плюс метринг текущего потребления. Создание дочки или добавление члена аудит-команды сверх квоты — управляемое поведение (мягкая блокировка/предупреждение, не жёсткий отказ по умолчанию). Респонденты (end users) в лицензию по умолчанию не входят — тарифицируются аудиторы и дочки; это можно пересмотреть отдельным решением.
