# Reference data: глобальная библиотека + адаптации тенанта; process universe — гибрид

По ответам клиента: (1) библиотека Framework/Control — **глобальная курируемая продуктовая** (шаблоны ведём мы), тенант **адаптирует** её своими копиями/переопределениями; (2) process universe — **гибрид**: общий каталог на уровне группы + локальные процессы дочки.

Следствие для модели: у reference-сущностей (Framework, Control, Business Process) два уровня — **global template** (tenant_id NULL, курируем мы, обновления стандартов централизованы) и **tenant instance/override** (tenant_id задан, кастомизации тенанта). RLS: глобальные шаблоны доступны всем на чтение; тенантные записи — только своему тенанту (совместимо с [[0003-shared-db-postgres-rls]] и [[0015-cross-tenant-user-membership]]). Обновление глобального стандарта не затирает адаптации тенанта — версии фреймворков с tracked changes ([[0010-tests-layer-separate-from-controls]] соседствует по логике версионирования).

Business Process: дочка оценивается по применимым процессам из группового каталога + может иметь локальные; групповая risk-карта консолидируется по общему каталогу, локальные видны на уровне дочки.
