# Один контейнеризованный артефакт для SaaS и on-prem

Платформа поставляется двумя способами: как SaaS под нашим управлением и как on-prem инсталляция для регулируемых клиентов (банки, финансовые группы — аудиторские данные содержат сведения об уязвимостях группы). Оба варианта собираются из одного контейнеризованного артефакта. Следствие-ограничение: разрешены только переносимые зависимости — Postgres, Redis, S3-совместимое объектное хранилище, SMTP; провайдеры email и AI — за абстракцией. Экзотичные managed-сервисы конкретного облака запрещены, иначе on-prem поставка развалится.
