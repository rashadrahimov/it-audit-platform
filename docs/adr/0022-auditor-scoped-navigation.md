# ADR-0022: Scoped-навигация внешнего аудитора (T-V50)

## Контекст

`membership.category` (data-model) различает тип участника, но в логике доступа не участвовал (parity-gap #4). Внешний аудитор (сотрудник аудиторской фирмы, приглашённый в тенант) не должен видеть внутренний админ-контур (настройки, роли, ключи, IAM) — только аудит-работу и комплаенс-базу. Vanta даёт такому пользователю «Auditor View».

## Решение

- **Значения `category`:** `internal` (сотрудник тенанта — полная навигация) | `auditor` (внешний аудитор — scoped). **Дефолт колонки изменён `auditor`→`internal`** (миграция 0087): большинство участников — внутренние; прежний дефолт `auditor` был некорректен и делал бы scoped-режим для всех. Демо-сид: admin/collaborator = `internal`, approver@demo.io = `auditor` (демо-аудитор).
- **Scope (решение Рашада, 20.07):** аудитор видит аудит-работу + read-only комплаенс-базу (controls/frameworks/policies/documents), risk и third-party контекст, активы/уязвимости; **скрыты** группа `org` (Organization & settings) целиком и IAM-разделы (`/iam`, `/access-reviews`). Правило — чистая `navForCategory(category)` в `lib/nav.ts` (`AUDITOR_HIDDEN_GROUPS` + `AUDITOR_HIDDEN_HREFS`), применяется в root-layout к сайдбару, туру и справочнику.
- **`category` наружу:** добавлен в `meTenants` (`/auth/me/tenants`) — веб берёт его для активного тенанта.

## Enforcement

V50 — **навигационный scope (UX), не replacement RBAC**: скрытие пунктов чистит интерфейс, но реальный контроль доступа остаётся за RBAC (роль внешнего аудитора без settings/edit) и per-entity ACL (ADR-0021). Прямой переход по URL на скрытый раздел по-прежнему гейтится правами роли. Полное «auditor не может открыть /config» обеспечивается тем, что аудиторские роли не имеют settings-прав — nav лишь не показывает недоступное.

## Последствия

- Плюс: чистый внешний вид для аудитора без раздувания ролей; `category` теперь несёт смысл.
- Минус: scope зашит в код (`AUDITOR_HIDDEN_*`), не настраивается из UI — при необходимости кастомизации per-tenant это отдельная задача. Список скрытого — источник правды здесь и в `lib/nav.ts`.
