# Полная мультиязычность (EN/AZ/RU) с первого релиза

UI и весь контент — библиотека контролей, шаблоны отчётов, email-уведомления — поставляются на английском, азербайджанском и русском с первого релиза: респонденты в дочках не всегда владеют английским, а отчёты регулятору могут требоваться на госязыке. Следствия: во всех контентных сущностях мультиязычные поля с fallback на английский; язык — атрибут пользователя (UI, письма) и атрибут отчёта (экспорт); перевод библиотеки контролей делается с помощью LLM с ручной вычиткой, иначе поддержка трёх языков соло-разработчику не по силам.
