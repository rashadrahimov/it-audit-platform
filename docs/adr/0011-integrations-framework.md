# Integrations-framework с capability-scope

Вводится абстракция **Connector** — интеграция с внешней или локальной системой, объявляющая набор **capabilities** (например: Access, Inventory, Vulnerabilities, TaskTracking, PersonnelSync, Evidence). Коннекторы — единый источник авто-заполнения: питают автотесты ([[0010-tests-layer-separate-from-controls]]), реестр активов, обнаружение вендоров, синхронизацию персонала и аккаунтов ([[0012-access-review-iam]]).

Причина: весь «сам заполняется» функционал референс-платформы держится на интеграциях; без этого слоя continuous compliance невозможен. Это фундамент, а не фича — проектируется с самого начала.

Ограничение (следствие [[0002-cloud-and-onprem-single-artifact]]): провайдеры за абстракцией. Для on-prem без интернета — коннекторы к локальным системам (LDAP/AD, локальный гипервизор, self-hosted тикет-система) либо ручной fallback; отсутствие коннектора не должно ломать работу платформы, только отключать авто-заполнение соответствующего домена.
