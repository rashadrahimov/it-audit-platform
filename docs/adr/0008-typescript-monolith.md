# Стек: TypeScript-монолит

Один язык на весь продукт: TypeScript — Next.js/NestJS + React, Postgres (Drizzle/Prisma), BullMQ поверх Redis для фоновых задач (напоминания о дедлайнах, email-рассылка), S3-совместимое хранилище для загружаемых файлов. Выбран из-за беглости разработчика, лучшей поддержки AI-инструментами и богатых UI-библиотек для таблиц и дашбордов (половина UI платформы). Альтернативы Python+Django и .NET отвергнуты: два языка в соло-проекте дороже, чем преимущества их бэкенд-фреймворков.
