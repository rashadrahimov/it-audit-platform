# Строим как продукт, а не заказную разработку

Платформа IT-аудита проектируется как переиспользуемый multi-tenant продукт; первый клиент (группа компаний с внутренней командой IT-аудита) — якорный заказчик. Альтернатива — разовая заказная разработка с передачей IP — отвергнута: требования и так включают мультитенантность, а рынок (GRC для групп компаний) не закрыт доступными аналогами. Следствие: в контракте с якорным клиентом IP на платформу остаётся у нас, клиент получает лицензию; все проектные решения принимаются с расчётом на повторную продажу другим группам.
