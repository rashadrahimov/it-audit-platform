# План работ EP-VPARITY — добор 100% паритета с Vanta

**Основание:** [parity-audit-2026-07-19.md](parity-audit-2026-07-19.md) (219 фич: full 15 / partial 113 / stub 24 / missing 67) и мандат клиента «весь функционал Vanta без исключений». Задачи — в [backlog.md](../backlog.md), эпик EP-VPARITY (T-V01…T-V49). Здесь — порядок исполнения.

**Принципы:**
1. Порядок по соотношению эффект/стоимость: сначала UI над готовым API (код бэкенда уже есть), потом системные паттерны, потом контент, потом новые сущности.
2. Каждый этап — вертикальный, заканчивается демонстрируемым результатом (правило ADR-0007 «показывать клиенту каждые 2–4 недели»).
3. Исполнение — автономными марафонами (шаблон E). Один этап ≈ один марафон-заход. Каждая задача — зелёный чекпоинт (build+verify+бэклог+commit) до перехода к следующей.
4. После каждого этапа: e2e-обход всех экранов (паттерн T-H29: 41+/41 OK) + скриншоты + пересчёт покрытия по [parity-audit-2026-07-19-full.txt](parity-audit-2026-07-19-full.txt).
5. Финал: повторный parity-аудит тем же методом. Критерий готовности эпика: **0 missing, 0 stub; partial только по позициям, явно помеченным [!]**.
